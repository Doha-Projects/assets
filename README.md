# Assets Repository

This repository stores assets including logos, images, and other media files.

## Directory Structure

- **`/logos`** - Logo files (PNG, SVG, etc.)

## How to Use Logos

Once you upload your logo to the `/logos` directory, use these permanent links:

**Example:**
- Raw CDN link: `https://raw.githubusercontent.com/Doha-Projects/assets/main/logos/your-logo.png`
- GitHub view: `https://github.com/Doha-Projects/assets/blob/main/logos/your-logo.png`

## Uploading Files

1. Go to the `/logos` folder
2. Click "Add file" → "Upload files"
3. Select your logo file
4. Commit the changes

Your logo will be accessible via the permanent links above.
